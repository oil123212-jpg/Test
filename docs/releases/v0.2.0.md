# 모모 웹 v0.2.0

- 날짜: 2026-10-31
- 기준 버전: v0.1.0
- 소스 브랜치: release/web-v0.2.0
- 버전 태그: v0.2.0
- 정적 배포 브랜치: gh-pages

## 변경 사항

GitHub Pages의 프로젝트 경로 `/Test/`를 지원합니다. 배포 시 아이콘과 AudioWorklet 경로가 도메인 루트로 잘못 지정되던 문제를 수정했습니다. 앱 화면의 버전도 v0.2로 표시합니다.

`build:pages`/`test:pages`, 정적 배포 스크립트, 버전을 선택할 수 있는 수동 GitHub Pages Actions 워크플로를 추가했습니다. v0.1.0 태그의 기존 코드는 유지합니다.

## 검증

`npm run test:pages`: TypeScript 및 Pages 경로 빌드 통과, 데스크톱/모바일 Chromium 30개 테스트 통과. 가상 마이크로 5초 녹음·24kHz 변환·재생·취소·삭제·권한 오류를 검증했습니다. 실제 모바일/Safari 청취 검증은 별도입니다.

## 사이트 활성화

GitHub Settings → Pages에서 **Deploy from a branch**, **gh-pages / (root)**를 선택해 저장합니다. 정적 브랜치 업로드와 실제 Pages 활성화는 별개입니다. 현재 실행 환경은 api.github.com과 Pages 호스트에 대한 연결이 차단되어 있어 API로 설정을 바꾸거나 공개 사이트 응답을 확인할 수 없습니다.

대안: Pages의 Source를 GitHub Actions로 설정하고 Deploy Momo to GitHub Pages 워크플로를 v0.2.0 입력으로 실행할 수 있습니다. 워크플로는 기본 브랜치에도 등록하며 실제 앱 소스는 선택한 버전에서 체크아웃합니다. Pages 지원 요금제와 저장소 권한은 해당 GitHub 설정에서 확인해야 합니다.

공개 사이트의 예상 주소는 `https://oil123212-jpg.github.io/Test/`입니다. 활성화/배포가 성공한 뒤 HTTPS, 마이크 권한, 데모·녹음·재생 및 version.json을 확인하세요. 이 문서의 주소는 예상 배포 주소이며 현재 접속 성공을 주장하지 않습니다.
