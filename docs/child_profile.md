# 아이 프로필 설정

상단 설정 버튼을 누르면 **프로필 설정**이 먼저 열리고, 같은 창의 두 번째 **오디오 설정** 탭에서 음량·장치를 조절합니다. 오디오 초기화는 프로필과 생활 시간표를 지우지 않습니다.

## 입력과 저장

- 이름: 1~30자. 글자·공백·일부 이름용 기호만 허용하고 앞뒤 공백을 정리합니다.
- 나이: 3·4·5·6세 중 선택합니다. 생년월일은 수집하지 않습니다.
- 좋아하는 것: **64개 항목**을 카테고리 구분이나 접힌 영역 없이 한 목록에 표시합니다. 여러 개 선택할 수 있으며 선택한 버튼은 맨 위로 이동합니다. 같은 버튼을 다시 누르면 해제되고 원래 순서로 돌아갑니다. 체크 표시와 `aria-pressed`로 상태를 표시하며 키보드 포커스를 유지합니다. 중복 ID는 한 번만 저장합니다.

입력은 로그인 전에도 가능하며 체험 로그인 후 **프로필 저장**을 눌러 DB에 저장합니다. 로그인 중 입력 초안을 유지합니다. 저장·조회 실패를 성공으로 표시하지 않으며 삭제 실패 시에도 미완료를 안내합니다. 프로필은 같은 브라우저에서 재로그인하면 복원됩니다. 로그아웃 시 탭의 프로필과 대화 연결을 정리하고 DB 원본은 유지합니다.

## PostgreSQL과 로그인

기존 웹 서비스의 **DATABASE_URL**과 브라우저별 세션을 재사용합니다. 최초 로그인 때 기존 `momo_life_guides`와 함께 `momo_child_profiles` 테이블을 `CREATE TABLE IF NOT EXISTS`로 준비합니다. 기존 시간표를 덮어쓰거나 삭제하지 않습니다.

`momo_child_profiles`의 열은 브라우저 쿠키의 SHA-256 해시인 `device_hash`, 그리고 `version/name/age/interests`만 담은 JSONB `profile`입니다. SQL 매개변수 바인딩으로 저장하고 프로필을 로그나 브라우저 영구 저장소에 남기지 않습니다. 음성·전사문은 저장하지 않습니다.

프로필 API는 기존 쿠키 경로 안의 `/api/life-guide/profile`이며 GET/PUT/DELETE를 제공합니다. 로그인·동일 Origin·요청 크기·필드 형식·나이 범위·관심사 목록을 서버에서 검사합니다. 프로필 삭제와 시간표 삭제는 서로 독립적입니다. 데이터 오류와 DB 오류에 이름이나 연결 문자열을 반환하지 않습니다.

저장 정책은 `parent-settings-v2`입니다. 로그인 팝업에 프로필의 수집 항목·보관·삭제·OpenAI 전송 목적을 명시했고, 이전 시간표 전용 동의 버전은 신규 로그인에서 거부합니다. 현재 로그인은 기존 브라우저 구분용 체험 방식이며 실제 계정 인증·보호자 본인 확인·다른 기기 간 동기화는 포함하지 않습니다.

## 모모 답변에 적용

기본 프롬프트 버전은 `momo-child-v2`입니다. 프로필을 저장하고 음성 전송에 동의해 대화하면 초기 세션과 각 답변 지침에 검증한 이름·나이·관심사를 참고 자료로 넣습니다.

- 3세: 아주 쉬운 한 문장 중심.
- 4세: 쉬운 1~2문장.
- 5세: 짧은 답변에 필요한 익숙한 예시 추가.
- 6세: 1~3문장 안에서 쉬운 이유·예시 설명.

이름은 가끔 다정하게 부르는 용도이고, 관심사는 놀이·예시에 어울릴 때만 활용합니다. 아이의 현재 화제·거절·안전을 우선하며 기존 라이프가이드 빈도 제어는 유지합니다. 이름은 JSON 참고 자료로 분리하고 지시문으로 취급하지 않도록 명시합니다. 자유 형식 관심사/나이 범위 밖 값은 허용하지 않습니다.

대화 중 수정·삭제는 허용된 `profile.update` 메시지로 다음 답변부터 반영하며, 연결 준비 중 변경도 ready 시 동기화합니다. 이미 제공자에 전달된 이전 프로필이나 대화 기록을 소급 삭제하는 기능은 아닙니다. OpenAI의 처리·보관 조건은 별도로 적용됩니다.

## 검증 범위

`npm run test:server`는 형식·관심사·Origin·로그인·브라우저 분리·SQL 저장/복원/삭제와 프로필별 지침 전송을 검증합니다. PostgreSQL 통합 검사는 테스트 DB URL을 `LIFE_GUIDE_TEST_DATABASE_URL`로 지정합니다. `npm run test:realtime`은 데스크톱/모바일 Chromium에서 탭 순서, 복수 선택/해제, 키보드 조작, 재로그인, 저장 실패, 오디오 초기화와 실시간 반영을 확인합니다. 모의 OpenAI 응답 검사는 실제 모델의 답변 품질 검증과 구분합니다.

프로필 최초 구현 검증 결과: 서버 48개(PostgreSQL 16 통합 포함), 전체 브라우저/오디오 검사 86개 통과. 실제 PostgreSQL을 연결한 프로필·생활 시간표 브라우저 검사 20개도 통과했습니다. 실제 Railway DB와 OpenAI 응답은 이 환경에서 직접 확인한 결과가 아닙니다.

화면 개편 후 `npm run test:realtime` 60개 검사를 통과했습니다. 로컬 녹음 UI 검사를 제거하고, 캐릭터 이미지 로딩·삭제된 오디오 경로·64개 항목 펼침·선택 정렬·키보드 해제와 기존 프로필/시간표/실시간 대화 흐름을 검증합니다. 이미지 원본은 `web/public/momo-character.png`이며 이미지 생성으로 제작했습니다.
