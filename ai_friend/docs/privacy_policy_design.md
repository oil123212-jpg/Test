# 개인정보 처리 설계 — 검토 초안

이 문서는 개발 설계이며 법률 준수나 제공자 승인을 검증한 문서가 아닙니다. Phase 0에서는 아동 음성을 사용하지 말고 성인 개발자/합성 음원으로 로컬 진단합니다.

| 데이터 | 목적 | Phase 0 저장 / 보관 | 미래 검토 사항 |
|---|---|---|---|
| 원본 음성 / PCM16 | 입력 진단, 요청 후 재생 | 메모리에서 테스트 동안만; 종료 시 소유 버퍼 덮어쓰기 | 명시적 목적/동의 없이는 저장 금지 |
| 전사문 / 대화 | 향후 대화 | 생성/저장하지 않음 | 최소 수집, 보관기간, 삭제 정책 |
| 이름·전화번호 등 직접 식별자 | 현재 불필요 | 수집/로그 금지 | 필요성부터 검토 |
| 기기 ID | 향후 서버 기기 인증 | 설정만; repr/로그에서 제외 | 가명 ID, 보호자와의 연결 최소화 |
| 연결 토큰 | 향후 단기 인증 | 자료형만; 실제 발급 없음 | 메모리 한정, 만료/철회, 로그 금지 |
| 보호자 동의 상태 | 데이터 처리 여부 | 기본 NOT_REQUESTED; 미검증 로컬 상태만 | 본인/법정대리인 확인, 증빙/철회 |
| 운영 이벤트/수치 | 오류 및 성능 진단 | 1MB × 현재 파일 + 백업 3개, 크기 기반 순환 | 접근 통제 및 시간 기반 보관기간 추가 검토 |

운영 로그의 크기 제한은 보관기간 제한을 대신하지 않습니다. 현재 테스트 종료 후 로그를 제거할 수 있으며 상용화 전 정해진 기간에 따라 자동 삭제하는 정책이 필요합니다. OS/드라이버 버퍼와 swap에 대한 완전 삭제는 보장하지 않습니다.

## 동의 및 철회

NOT_REQUESTED → PENDING → (미래의 검증된 절차에서만) GRANTED. 철회하면 REVOKED입니다. Phase 0에는 GRANTED를 생성하는 기능과 보호자 본인/법정대리인 확인을 완료했다고 주장하는 구현이 없습니다. 테스트의 GRANTED 상태는 mock으로만 주입합니다.

실서비스는 처리 목적/항목/보관기간/수탁·국외 이전 등을 보호자에게 안내하고 검증된 법정대리인의 동의를 확인해야 합니다. 철회 시 새 수집/저장/전송을 즉시 중단하고 진행 중 세션을 취소하며, 동의 증빙과 삭제 대상/보관 의무를 분리해야 합니다. 이 흐름은 구현/법적 검토가 필요합니다.

저장 허용은 설정 플래그와 현재 GRANTED 상태를 모두 요구합니다. 플래그 자체가 동의가 아닙니다. **외부 전송은 GRANTED여도 Phase 0에서 항상 금지**됩니다. 제공자 조건 충족은 별도 판단 항목이며 환경변수 하나로 활성화하지 않습니다.

## 삭제

`delete_local_user_data(data_root)`는 앱 전용 디렉터리의 `.wav`, `.pcm`, `.txt`, `.json` 파일을 삭제합니다. 소스/홈 디렉터리를 전달하지 마세요. 심볼릭 링크, 중첩 디렉터리, 알 수 없는 파일은 작업 전에 거부합니다. 기본 진단은 파일을 생성하지 않으므로 삭제 대상도 없습니다. 로그는 개인정보를 포함하지 않으며 별도 운영 정책으로 제거합니다.

향후 사용자별 데이터 분리, 동의 철회와 삭제 연결, SQLite 트랜잭션, 백업/클라우드 사본 삭제, 삭제 결과 증빙을 설계해야 합니다. 현재 unlink는 안전한 물리 덮어쓰기를 보장하지 않습니다.

## 외부 제공자와 상용화 전 검토

현재 외부로 전송되는 음성/전사문/개인정보는 없습니다. Phase 1에서 검토할 전송 후보는 오디오, 세션 이벤트, 최소 기기 인증 정보입니다. 실제 제공자별 전송 항목/지역/보관/학습 사용/재위탁/국외 이전 조건은 최신 계약과 문서로 확인해야 합니다. OpenAI 및 Gemini의 아동 이용 조건을 확인하지 않은 상태에서 보호자 동의만으로 연결하지 않습니다.

국내 검토 항목: 개인정보 보호법상 만 14세 미만 아동에 대한 법정대리인 동의와 확인 방법, 수집 최소화와 목적 제한, 민감정보/건강·감정 추론 여부, 처리방침·수탁·제3자 제공·국외 이전, 정보주체의 열람/정정/삭제/처리정지, 안전성 확보조치, 유출 대응, 서버/백업 보관기간. 관계 법령·서비스 형태·계약에 대한 전문가 검토가 필요하며 여기서는 충족했다고 주장하지 않습니다.

외부 전송 금지 조건: Phase 0 전체, 미요청/대기/철회/미검증 동의, 제공자 요건 미확인, 적용 법적 요건 미충족, 처리 목적/대상 불명확, 만료·실패한 인증, 철회 후 활성 세션, 불필요한 식별자 포함. Phase 1에서는 이 조건들을 전송 직전에도 검사해야 합니다.
