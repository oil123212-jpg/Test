처리하는 정보와 목적

체험 로그인에는 이메일·전화번호가 필요하지 않습니다. 기기 구분용 쿠키와 로그인 세션을 사용합니다. 선택한 별명, 3~6세 나이, 관심사와 생활 시간표는 맞춤 대화에 사용하고 Railway의 PostgreSQL에 브라우저 구분값과 함께 저장합니다. 실명이나 생년월일을 입력하지 마세요.

음성 처리 및 외부 전송

음성 전송에 동의하고 대화를 시작하면 마이크 음성이 암호화된 연결로 Railway 서버를 거쳐 미국 OpenAI의 Realtime API에 전달됩니다. 답변을 만들 때 선택한 프로필·해당 생활 화두·기억 주제도 전달될 수 있습니다. 거부하면 실시간 음성 대화를 사용할 수 없습니다. 카메라는 사용하지 않으며 모모는 음성 파일이나 대화 원문을 DB·브라우저에 보관하지 않습니다.

48시간 대화 기억

음성 대화에 동의하고 시작하면 자동으로 OpenAI가 발화를 임시로 문자화하고 모모가 허용 목록에서 주제를 찾습니다. 문장, 이름, 연락처, 상세 장소, 건강 정보는 기억 항목이 될 수 없습니다. 해당하는 주제가 있으면 가장 최근 주제 코드·생성 시각과 초기화 구분값을 이 브라우저의 만료 쿠키에 저장합니다. 같은 사이트에 요청할 때 쿠키가 서버로 전송될 수 있습니다. 같은 브라우저에서 다음 대화를 시작하면 주제를 답변에 사용합니다. 다른 브라우저나 기기와 동기화하지 않습니다.

보관 기간과 파기

각 주제는 생성 후 48시간이 지나면 만료되어 다시 사용되지 않습니다. 다시 열거나 읽는 것만으로 기간이 연장되지 않습니다. 새 주제가 생기면 덮어씁니다. 프로필·생활 시간표는 직접 삭제할 때까지 DB에 남으며 기기 구분 쿠키는 최대 1년입니다. 브라우저 쿠키를 지우면 기존 DB 설정에 접근하지 못할 수 있으므로 해당 화면에서 먼저 삭제하세요. 주간 리포트나 세션 종료 후 별도 분석은 제공하지 않습니다.

열람·수정·삭제와 동의 철회

설정 → 프로필 설정 → 대화 기억 초기화를 누르면 로그인 없이 해당 브라우저의 기억을 즉시 삭제하고 진행 중인 대화를 닫습니다. 다음 대화에서는 새로 언급한 주제부터 기억합니다. 음성 전송 동의를 해제하거나 이용 종료를 누르면 연결이 종료됩니다. 프로필을 삭제하면 대화 기억도 함께 삭제합니다. 프로필은 설정에서, 생활 시간표는 라이프 가이드에서 확인·수정·삭제하세요. 기억 초기화의 대상은 대화 주제입니다.

제공자 보관 및 보호 조치

OpenAI API 데이터는 기본적으로 모델 학습에 사용되지 않습니다. 악용 모니터링 로그는 기본 설정에서 최대 30일 보관될 수 있고 법적 요구 등 예외가 있습니다. 모모의 48시간 만료 및 초기화는 OpenAI나 호스팅 사업자의 별도 로그에 적용되지 않습니다. 이 시연에서 OpenAI의 무보관 설정(ZDR)이나 Railway의 저장 국가를 확인하지 않았습니다. 실제 아동 개인정보를 보내지 마세요.
