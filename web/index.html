시작 전, 확인해 주세요

개인정보 처리 안내를 확인하고 체험을 시작해 주세요. 계정 정보를 입력하지 않는 로컬 오디오 체험이에요.

어떤 정보를 처리하나요?

선택한 마이크의 음성과 장치 정보를 오디오 점검에 사용해요. 실시간 대화를 선택하면 음성을 AI 응답 생성에 사용합니다. 이 사이트는 전사문을 표시하거나 저장하지 않아요.

어디에, 얼마나 보관하나요?

음성은 현재 탭의 메모리에만 임시 보관해요. 삭제, 이용 종료, 탭 비활성화 또는 페이지 종료 시 정리하며 파일이나 브라우저 저장소에 저장하지 않아요.

외부로 보내나요?

로컬 오디오 테스트는 외부로 보내지 않아요. 실시간 대화는 별도 동의 후 Railway 서버와 OpenAI로 음성을 전송합니다. 제공자 데이터 처리 조건과 호스팅 접속 기록 정책은 별도로 적용됩니다.

생활 시간 설정은요?

체험 로그인 후 선택한 생활 시간표와 브라우저 구분용 식별자를 Railway PostgreSQL DB에 저장해요. 브라우저를 기억하는 쿠키는 최대 1년간 유지되며 시간표는 직접 삭제할 때까지 남아요. 음성·대화 내용과 라이프가이드 연결 동의는 DB에 저장하지 않아요. 라이프가이드 연결을 켜면 대화 중 현재 생활 항목과 시간을 OpenAI에 전달해요. 라이프 가이드에서 시간표를 삭제할 수 있어요. 계정 인증 없이 이 브라우저를 구분하는 테스트용 로그인입니다.

아이 프로필은요?

보호자가 입력한 아이의 이름, 3~6세 나이, 선택한 관심사를 PostgreSQL DB에 저장해요. 음성 대화 시 이 정보를 OpenAI에 전달해 답변을 맞춰요. 설정의 프로필 삭제로 지울 수 있으며 다른 브라우저와는 구분돼요. 입력하지 않아도 기본 음성 대화를 이용할 수 있어요.

동의하지 않으면 어떻게 되나요?

실제 마이크 테스트와 실시간 대화는 사용할 수 없지만 합성 음원 데모는 이용할 수 있어요. 이용 종료를 누르면 동의를 철회하고 임시 음성을 지울 수 있어요.

브라우저 마이크 권한은 별도로 요청해요. 이 동의는 보호자 본인·법정대리인 확인을 대신하지 않아요. 실시간 음성 전송 동의는 대화 화면에서 따로 선택해 주세요.

브라우저가 출력 장치 선택을 지원하면 여기에서 바꿀 수 있어요.

모모, 이렇게 시작해요

  1. 가볍게 체험하기

    데모 음원은 마이크 권한 없이 합성 소리로 녹음·재생 흐름을 보여줘요. AI 대화는 아니에요.

  2. 내 마이크 확인하기

    체험 로그인에서 안내에 동의한 뒤 마이크 모드와 권한을 확인하세요. 녹음을 누르면 최대 5초 동안 수집하고 마이크를 닫아요.

  3. 직접 눌러 들어보기

    다시 듣기를 눌러야 재생해요. 언제든 중단하거나 지울 수 있어요.

마이크를 사용하려면 보안 연결과 브라우저의 마이크 권한이 필요해요. Safari·모바일에서는 출력 장치 선택이 제한될 수 있어요.
