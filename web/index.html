알림 대신, 대화 속에서 가볍게

매일 반복할 시간을 30분 단위로 여러 개 선택해 주세요. 해당 시간대에 대화하면 약 3번 중 1번 자연스럽게 이야기를 꺼내요. 같은 항목은 한 대화의 같은 30분 안에서 한 번만 제안해요.

예: “오늘은 어떤 반찬이 먹고 싶어?” · “자기 전에 어떤 이야기를 들으면 좋을까?” · “장난감은 어디에 쉬게 해 줄까?”

시간이 되어도 자동으로 말을 걸거나 알림을 보내지 않아요. 부모님용 설정 화면이며 별도 계정 인증 기능은 없어요.

기기 시간이 바뀌어도 이 시간대를 기준으로 해요. 선택하지 않은 시간에는 생활 화두를 먼저 꺼내지 않아요.

체험 로그인 후 저장된 생활 시간을 불러올 수 있어요.

모모와 대화하기 →

생활 시간표는 PostgreSQL DB에 저장돼요. 이 브라우저를 기억하는 쿠키로 구분하며, 같은 브라우저에서 체험 로그인하면 다시 불러와요. 쿠키를 삭제하거나 다른 브라우저를 쓰면 별도 기기로 구분돼요. DB에는 시간표와 구분용 식별자만 저장해요. 생활 이야기 연결 동의는 DB에 저장하지 않으며, 로그인할 때마다 직접 켜 주세요.

시작 전, 확인해 주세요

개인정보 처리 안내를 확인하고 체험을 시작해 주세요. 계정 정보를 입력하지 않는 로컬 오디오 체험이에요.

어떤 정보를 처리하나요?

선택한 마이크의 음성과 장치 정보를 오디오 점검에 사용해요. 실시간 대화를 선택하면 음성을 AI 응답 생성에 사용합니다. 이 사이트는 전사문을 표시하거나 저장하지 않아요.

어디에, 얼마나 보관하나요?

음성은 현재 탭의 메모리에만 임시 보관해요. 삭제, 이용 종료, 탭 비활성화 또는 페이지 종료 시 정리하며 파일이나 브라우저 저장소에 저장하지 않아요.

외부로 보내나요?

로컬 오디오 테스트는 외부로 보내지 않아요. 실시간 대화는 별도 동의 후 Railway 서버와 OpenAI로 음성을 전송합니다. 제공자 데이터 처리 조건과 호스팅 접속 기록 정책은 별도로 적용됩니다.

생활 시간 설정은요?

체험 로그인 후 선택한 생활 시간표와 브라우저 구분용 식별자를 Railway PostgreSQL DB에 저장해요. 브라우저를 기억하는 쿠키는 최대 1년간 유지되며 시간표는 직접 삭제할 때까지 남아요. 이름·음성·대화 내용과 연결 동의는 DB에 저장하지 않아요. 연결하기를 켜면 대화 중 현재 생활 항목과 시간을 OpenAI에 전달해요. 라이프 가이드에서 시간표를 삭제할 수 있어요. 계정 인증 없이 이 브라우저를 구분하는 테스트용 로그인입니다.

동의하지 않으면 어떻게 되나요?

실제 마이크 테스트와 실시간 대화는 사용할 수 없지만 합성 음원 데모는 이용할 수 있어요. 이용 종료를 누르면 동의를 철회하고 임시 음성을 지울 수 있어요.

브라우저 마이크 권한은 별도로 요청해요. 이 동의는 보호자 본인·법정대리인 확인이나 아동 음성의 외부 전송 허용을 의미하지 않아요.

오디오 설정

디지털 신호는 최대 20%로 제한해요. 실제 음압은 기기에 따라 다르므로 기기 볼륨도 낮춰 주세요.

브라우저가 출력 장치 선택을 지원하면 여기에서 바꿀 수 있어요.

모모, 이렇게 시작해요

  1. 가볍게 체험하기

    데모 음원은 마이크 권한 없이 합성 소리로 녹음·재생 흐름을 보여줘요. AI 대화는 아니에요.

  2. 내 마이크 확인하기

    체험 로그인에서 안내에 동의한 뒤 마이크 모드와 권한을 확인하세요. 녹음을 누르면 최대 5초 동안 수집하고 마이크를 닫아요.

  3. 직접 눌러 들어보기

    다시 듣기를 눌러야 재생해요. 언제든 중단하거나 지울 수 있어요. 성인용 음성 확인 체험으로 사용해 주세요.

마이크를 사용하려면 보안 연결과 브라우저의 마이크 권한이 필요해요. Safari·모바일에서는 출력 장치 선택이 제한될 수 있어요.
