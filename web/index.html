PRIVACY BY DEFAULT

안전함이 기본이에요

이 브라우저에서 무엇을 처리하고 있는지 투명하게 알려드려요.

목소리는 잠깐만

음성은 탭의 메모리에서만 처리해요. 파일, 데이터베이스, 브라우저 저장소에 남기지 않아요. 새로고침하거나 세션을 지우면 사용할 수 없어요.

음성 저장 안 함

외부로 보내지 않아요

AI 제공자나 서버로 음성·전사문을 전송하지 않아요. 음성 인식과 대화 생성도 실행하지 않아요. 웹 파일을 불러오는 요청만 발생해요.

외부 음성 전송 차단

동의를 대신하지 않아요

마이크 접근 허용은 브라우저 사용 권한이에요. 보호자의 개인정보 처리 동의나 법정대리인 확인을 완료한 것으로 간주하지 않아요.

보호자 동의 확인 전

현재 세션 정리

진행 중인 녹음·재생을 멈추고, 마이크 연결과 보관 중인 임시 녹음을 정리해요. 체크리스트도 초기화해요.

운영체제·브라우저 내부 복사본의 완전한 물리 삭제를 보장하지는 않아요. 탭이 숨겨지거나 페이지를 떠날 때도 음성 세션을 정리해요.

PHASE 1 · 아직 연결하지 않아요

AI를 만나기 전에

아동 대상 제공자 조건, 개인정보 처리, 검증된 보호자 동의, 서버 인증과 비용 제한을 먼저 검토해야 해요. 브라우저에 장기 API 키를 입력하지 마세요.

  1. 제공자의 만 3~6세 이용 및 음성 보관 조건 확인
  2. 보호자 계정·법정대리인 확인·동의 철회 절차 설계
  3. 브라우저 → 인증·중계 서버 → AI 연결 구조 구현
  4. 성인/합성 음원으로 취소·만료·장애·비용 상한 시험

오디오 설정

디지털 신호는 최대 20%로 제한해요. 실제 음압은 기기에 따라 다르므로 기기 볼륨도 낮춰 주세요.

브라우저가 출력 장치 선택을 지원하면 여기에서 바꿀 수 있어요.

모모, 이렇게 시작해요

  1. 가볍게 체험하기

    데모 음원은 마이크 권한 없이 합성 소리로 녹음·재생 흐름을 보여줘요. AI 대화는 아니에요.

  2. 내 마이크 확인하기

    마이크 모드를 선택하고 권한을 확인하세요. 녹음을 누르면 최대 5초 동안 수집하고 마이크를 닫아요.

  3. 직접 눌러 들어보기

    다시 듣기를 눌러야 재생해요. 언제든 중단하거나 지울 수 있어요. 성인 개발자용 로컬 점검으로 사용해 주세요.

마이크는 보안 연결(HTTPS)이나 로컬 개발 환경에서만 사용할 수 있어요. Safari·모바일에서는 출력 장치 선택이 제한될 수 있어요.
